Desktop Pets for Windows

Install and start:
1. Make sure Python 3 is installed.
2. Double-click install_autostart.bat.
   If Pillow is missing, the script installs it. That step needs internet.
3. The pet starts right away and will start again when you sign in to Windows.

Start the pet later:
- Double-click run_now.bat.

Uninstall autostart:
- Double-click uninstall_autostart.bat. It removes the Startup shortcut and
  stops a running desktop pet app.

Quit or stop the pet:
- Right-click the pet and choose Quit.
- Or open Task Manager, find the app's pythonw.exe process, and end the task.

The app works offline after Pillow is installed.
If you move the project folder, run install_autostart.bat again.
